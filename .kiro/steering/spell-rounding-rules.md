# R3 - Rounding Lua: Magnitude Rounding Rules

Governs `scripts/R3RoundingLua/load.lua`, a separate plugin from R3 - Spells Lua.
At startup it rounds the magnitude ranges of the buyable spells listed in
`scripts/R3RoundingLua/spells.lua` (generated by `tools/gen_spells.py`).

## Rule (from old R3)

| Condition                  | Rule                                     |
|----------------------------|------------------------------------------|
| Ranged magnitude (min≠max) | each end becomes 1 or a multiple of 5    |
| Fixed magnitude (min=max)  | exempt, kept as is                       |
| Duration                   | exempt, never changed                    |
| Effect without magnitude   | exempt (stored magnitude is not used)    |

Each end of a range:

- 1 or less: kept.
- 2: becomes 1.
- 3 or 4: becomes 5.
- 5 and above: nearest multiple of 5 (12 -> 10, 13 -> 15).

Examples: 5-11 -> 5-10, 2-20 -> 1-20, 3-12 -> 5-10, 10-24 -> 10-25.

## Cost

- Autocalc spells: the engine prices them from the rounded magnitudes.
- Non-autocalc spells: `cost = round(cost * newCalc / oldCalc)`, minimum 1,
  with both formula costs at the loaded base costs (same formula as
  `spell-conversion-rules.md`). A stored cost of 0 stays 0.

## Independence

R3 - Rounding and R3 - Spells work in either order. Rounding changes only
magnitude; Spells changes only duration and base cost. Each scales the stored
cost by its own formula ratio, so the results combine.
