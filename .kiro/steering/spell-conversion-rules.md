# R3 - Spells Lua: Spell Conversion Rules

Governs `scripts/R3SpellsLua/load.lua`. At startup the plugin converts the listed
buyable spells (`scripts/R3SpellsLua/spells.lua`, generated by
`tools/gen_spells.py`) to the effect base costs the game has. It does not set
base costs: R3 - Core does (`scripts/R3CoreLua/data.lua`, menu toggle). The
vanilla costs the spells were made for: `scripts/R3SpellsLua/vanilla.lua`
(hand-maintained). Names: `names.lua`.

## Factor

Per effect:

```
factor = vanilla base cost / base cost in the game
```

`base cost in the game` is read from the loaded effect record: R3 when Core
applied its costs, vanilla when the Core toggle is off or Core is not enabled.
Factor 1 means nothing to do, so the plugin works with or without Core.

The classification is about the base cost change, in either direction:

- **Whole**: the base cost is multiplied or divided by a whole number.
  1 -> 0.1 (/10), 2 -> 0.5 (/4), 40 -> 80 (x2), 1 -> 4 (x4).
  Factors 10, 4, 0.5, 0.25.
- **Fractional**: the change is not a whole multiple either way.
  5 -> 8 (x1.6), 4 -> 6 (x1.5), 1 -> 2.5 (x2.5), 9 -> 8.

## Clean multiplier

The duration is scaled only when the multiplier applies cleanly: the change is
whole **and** duration x factor is a whole number of seconds, at least 1s.
No rounding, no minimum clamp.

- Clean: 5s x 4 = 20s, 30s x 1/2 = 15s, 10s x 5 = 50s.
- Not clean: 3s x 1/2 = 1.5s, 1s x 1/3 = 0.33s, 30s x 1/8 = 3.75s.

When the multiplier is not clean, the effect is kept as is (magnitude and
duration unchanged). The cost then follows the base cost change: the engine
for autocalc spells, the cost algorithm for non-autocalc spells.

## Per-effect rule

| Case                                  | Effect                | Autocalc spell | Non-autocalc spell                 |
|---------------------------------------|-----------------------|----------------|------------------------------------|
| Clean multiplier                      | duration x factor     | nothing else   | duration x factor + cost algorithm |
| Whole change, not clean               | kept as is            | nothing        | cost algorithm                     |
| Fractional change                     | kept as is            | nothing        | cost algorithm                     |

- Magnitude, area and range are never changed.
- Effects without duration (Lock, Open, ...) keep their values; only the cost
  algorithm applies to them.
- Elemental damage (Fire 5->8, Frost 5->8, Shock 7->8, Poison 9->8) has
  fractional factors, so it falls under the fractional rule. No special case.

## Multi-effect spells

Apply the per-effect rule to each effect separately. The cost algorithm runs
once per spell over all its effects, for non-autocalc spells only.

## Cost algorithm (non-autocalc only)

```
vanillaCalc = engine cost of the original spell at the vanilla base costs
actual      = stored spell cost
newCalc     = engine cost of the converted spell at the base costs in the game
compensated = round(actual * newCalc / vanillaCalc), minimum 1
```

A stored cost of 0 (free spells, e.g. Wabbajack) stays 0.


- The engine cost mirrors `MWMechanics::calcEffectCost` (GameSpell method,
  OpenMW source `apps/openmw/mwmechanics/spellutil.cpp`) plus x1.5 for
  on-target effects. `fEffectCostMult` cancels in the ratio and is left out.
- Autocalc spells are never repriced: OpenMW computes their cost from the base
  costs at runtime.
